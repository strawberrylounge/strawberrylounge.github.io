# Portfolio

Cynthia Kim의 포트폴리오 사이트입니다.

- React 19 + Vite
- MUI, Emotion, GSAP, Embla Carousel

## Requirements

- Node.js 20

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — 개발 서버 실행
- `npm run build` — 프로덕션 빌드
- `npm run preview` — 빌드 결과 미리보기
- `npm run lint` — ESLint 검사
- `npm run deploy` — GitHub Pages 배포 (build 후 `dist` 배포)
